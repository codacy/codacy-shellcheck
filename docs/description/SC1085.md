## Did you forget to move the ;; after extending this case item?

### Problematic code:

```bash
case $options in
  foobar) echo foo ;; echo bar;;
  *) echo unknown option ;;
esac
```

### Correct code:

```bash
case $options in
  foobar) echo foo ; echo bar;;
  *) echo unknown option ;;
esac
```

### Rationale:
There should be no statements between `;;` and the next case item.
[Source](https://github.com/koalaman/shellcheck/wiki/SC1085)
